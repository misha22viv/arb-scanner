Проверка источника коэффициентов

Тест проверяет публичные JSON-адреса BetScoper прямо из браузера. Он ничего не отправляет букмекерам, не входит в аккаунты и не делает ставок.

Источник
BetScoper API · https://betscoper.ru/api/v1/

Проверяем список букмекеров и предстоящие футбольные матчи. Если браузер блокирует запрос (CORS), это будет показано отдельно от ошибки сервера.

Ожидает запуска

1. Список букмекеров

Не проверено
Нажми «Проверить соединение».

2. Предстоящие матчи

Не проверено
Нажми «Проверить соединение».

3. Коэффициенты первого найденного матча

Ожидает список матчей
Будет проверено автоматически, если API вернёт матч со slug.

Что означают результаты

Успех — браузер получил JSON.

CORS / Failed to fetch — сайт API может работать, но не разрешает запросы с GitHub Pages. Тогда понадобится серверный посредник.

HTTP 4xx/5xx — сервер ответил ошибкой; текст ответа будет показан выше.
